<h1>📖 Overview</h1>
SUNLIGHT is a professional website showcasing products for a company specializing in electrical light bulbs. The project features an attractive and modern user interface that displays lighting products in beautiful shapes and high quality, with a smooth and responsive user experience across all devices.

<h2>✨ Features</h2>

🎨 Modern & Attractive Design - Professional UI that highlights product beauty
📱 Fully Responsive - Works efficiently on all screen sizes
🎭 Advanced Visual Effects - Smooth animations and transitions using Swiper
⚡ Fast Performance - Optimized code for quick browsing experience
🛍️ Professional Product Display - Organized and easy-to-browse product gallery

<h2>🛠️ Technologies Used</h2>

HTML5 - Page structure
CSS3 - Styling and layout
JavaScript (ES6+) - Interactivity and dynamic functionality
Swiper.js - Professional product showcase

<h2>💡 Skills Gained</h2>

Through developing this project, the following skills were acquired and improved:

🔍 Research & Self-Learning - Finding technical solutions and best practices
🎨 Advanced CSS Skills - Complex designs and visual effects
🔗 CSS-JavaScript Integration - Dynamic interaction between design and programming
📚 Using External Libraries - Exploring diverse JavaScript libraries like Swiper
📱 Responsive Design Development - Advanced responsive design techniques
